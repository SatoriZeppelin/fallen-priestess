# 妹神官 · Fallen Priestess

由 SillyTavern「主脚本」正则中的整页 HTML 按 [Larimar](https://github.com/SatoriZeppelin/Larimar) 目录拆开。

```
├── index.html           # 入口
├── backend/             # 预留：解析 / 存档 / 变量（目前仍在 interface/app.js）
├── interface/           # 舞台、标题、设置、地图、Hstatus
├── resource/            # 资源映射、地图配置
└── preset/              # 原始正则脚本备份
```

本地直接打开 `index.html` 即可（资源走 Hugging Face / Catbox）。
